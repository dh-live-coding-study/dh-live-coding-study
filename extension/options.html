LeetCode 제출 수집

수집을 켜면 이 브라우저에서 새로 제출하고 정답 판정을 받은 Java 코드가 공개 저장소의 PR로 전송됩니다. 로그인 쿠키와 LLM API 키는 GitHub에 전송하지 않습니다.

전송 권한과 PR 원문 확인용 읽기 권한이 필요합니다. 토큰은 이 확장의 로컬 저장소에 보관합니다. 브라우저 프로필에 접근할 수 있는 사람은 토큰도 읽을 수 있으므로 공용 기기에 저장하지 마세요. 설정 후 LeetCode 탭을 새로 고칩니다.

대기 중인 제출

실행 요청 접수는 PR 생성 완료를 뜻하지 않습니다. GitHub Actions에서 결과를 확인하세요. 판정 대기 중이면 로그인한 LeetCode 탭을 열고 판정을 재확인합니다. 알려진 오답은 임시 원문을 삭제하며, 알 수 없는 판정은 보관하고 다시 확인합니다. PR에 동일 코드가 있는 것을 확인해야 대기열에서 원문을 삭제하며, 확인되지 않은 기록은 자동으로 지우지 않습니다.
